# S2Brake: Let your minecarts brake
One problem I had with making a road system is having minecarts keep going. That's why I (with a bit of help from forums and GPT, Java is hard imo 😢) made a plugin that lets your brake on minecarts.

Please this is is a PLUGIN meant for servers. If you want a mod, I recommend [Minecart Braking](https://modrinth.com/mod/minecart-braking), which does the same thing.

## Supported Plugin Loaders
- Paper
- Folia

## How to Use
Drag the JAR file into your **plugins** folder in your server. That's it!

To set the speed, go to **speed** in the plugin's config.yml file.
This is how much the minecart's speed multiplies by every tick, so a lower speed = faster brakes.
- **Instant:** 0
- **Very Fast:** 0.1
- **Fast:** 0.25
- **Normal (Default):** 0.5
- **Slow:** 0.75
- **Do Nothing:** 1
- **Accelerate???:** >1
